REKA QUEUE NOTIFIER FOR LINUX

1. Install: sudo apt install ./reka-queue-notifier-linux.deb
2. Connect: reka-queue-notifier --setup
3. Enter the queue server URL and your operator account.

The notifier starts automatically after the user logs in. Check it with:
reka-queue-notifier --status

Reconfigure at any time by running --setup again.
