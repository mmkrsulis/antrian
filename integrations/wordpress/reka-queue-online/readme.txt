Connect WordPress to Reka Queue Management for online registration and visitor check-in.

== Installation ==
1. Upload and activate reka-queue-online.zip.
2. Open Settings > Reka Queue.
3. Enter the queue server URL and ONLINE_API_KEY.
4. Use [reka_queue_form] and [reka_queue_checkin] on WordPress pages.

The API key is used only by server-side WordPress requests and is never sent to the visitor browser.
