# Berkontribusi ke Reka Queue

Terima kasih telah membantu mengembangkan Reka Queue Management.

1. Fork repositori dan buat branch dari `main`.
2. Jangan commit `.env`, kredensial, database, backup, atau data pengguna.
3. Buat perubahan sekecil dan sejelas mungkin.
4. Jalankan pengujian yang relevan di folder `tests/`.
5. Buka pull request yang menjelaskan masalah, solusi, dan cara pengujiannya.

Dengan mengirim kontribusi, Anda menyetujui bahwa kontribusi tersebut
dilisensikan berdasarkan GNU General Public License v3.0 atau versi setelahnya
(GPL-3.0-or-later).

Untuk laporan kerentanan, ikuti petunjuk pada `SECURITY.md` dan jangan membuka
issue publik sebelum perbaikan tersedia.
